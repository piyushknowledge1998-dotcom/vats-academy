# Vats Academy

Official website prototype for Vats Academy.

## V1 scope

- Four learning pathways: Civil Services, Higher Education, Class 6–12, General Competition
- Course catalogue with category filtering
- Test Books / practice library structure
- Faculty and mentor area
- Resources area
- About and enquiry sections
- Responsive, dependency-free HTML/CSS/JavaScript

## Local preview

Open `index.html` in a browser, or serve the folder with any simple static HTTP server.

## GitHub Pages

In the repository, go to **Settings → Pages**, choose **Deploy from a branch**, select `main` and `/ (root)`, then save. GitHub Pages will publish the static site.

## Content policy for launch

The V1 deliberately avoids invented faculty credentials, student counts, testimonials, fees or other claims. Replace placeholders only with verified academy information.
